# Cuckoo panel readability

Scope: theme-aware Cuckoo panel content only; no cadence, inference, stored
report schema, plain-text/RPC format, badge, or other extension changes.

## Design

- Show newest checkpoint/objectives before configuration; leave runtime faults
  at the top rather than below a long report.
- Accent/bold checkpoint and numbered objective headings; muted request IDs,
  branch/time/entry metadata and explicit saved-not-live-verification qualifiers.
- Separate labeled fields with whitespace: Progress and ETA use accent;
  Obstacles, Issues and Bottlenecks use warning labels. These identify categories,
  not inferred severity/completion. Model-supplied values stay literal.
- Explicit error headings and retained literal raw text for invalid/interrupted
  reports, even when raw JSON is parseable. Preserve legacy missing-value wording.
- Keep the shared bounded StatusView for wrapping, keyboard/wheel scrolling,
  retained border, repeat-click toggle and keyboard dismissal. Regenerate themed
  content on invalidation rather than storing rendered colors.

## 2. Decision ownership and eligible responsibilities

The host already owns observed source roles, file/action identities, source-frontier and CAS validation. Keep these mechanical fields deterministic. A source actor recorded by the host must not be inferred by a classifier. The curator owns interpreted propositions, node descriptions, proposed semantic relation endpoints and account revisions. The projection owner preserves governing source/qualifications; a classifier cannot discard unresolved intent to save context.

A narrow `DecisionPort` accepts a source-bound `DecisionBatch` and returns a derived `DecisionAssessment` or explicit unavailable/invalid outcome. Requests bind scope/frontier, exact source spans, candidate IDs/content revisions, label definitions/schema version, ordered question set and intended task. Responses retain declared/observed model revision, server identity where available, complete option-score maps, raw versus calibrated score identity, input completeness, timing and failure status. No credentials or hidden reasoning in receipts. Missing and false/zero are different; malformed scores are not abstentions.

Map this interface to the COMPLETE frozen006 curation path, not the early tracked README's unfinished integration. In006, `curation.py::Curator.settle` constructs a fixed-prefix attempt, retrieves prior source within that attempt, decodes a proposal, applies its atomic delta, seals capture and publishes to the journal. `projection.py::qualified_capsule` combines protected facts, model assertions and applicability; `trial.py::Trial.phase_loop` settles then actually delivers alignment to the worker. Freeze the new experiment's imported baseline source identity explicitly rather than equating these Nix sources to a tracked commit.

Classifier receipts live in a separately addressable derived-assessment store, attached to that SAME fixed prefix. They are NOT newly eligible primary events, new Human/tool observations or an extra curation trigger. Recording delivery changes neither eligible source IDs, source actors, successful frontier nor explicit-intent eligibility. A host receipt may attest returned score bytes/transport, never the truth of the predicted label. Any citation of advice remains an attributed model assessment; it cannot be used as independent qualifying evidence for a Human requirement or host-observed fact. Negative tests must show no feedback self-citation or advice-triggered frontier inflation.

Compare placements:

1. Before the existing curator: attach bounded classifications as attributed advisory evidence beside original sources. The curator can disagree; record actual delivery and use. This reaches ordinary semantic planning without granting classifier graph-write authority, but may increase latency and confirmation bias and does not automatically remove a call.
2. Inside a decomposed classification stage: after source-grounded proposition/pair proposal, CLEF replaces the matched LLM classifier for eligible decisions; explicit unknown/abstention routes to the original LLM classifier. A deterministic composer submits the resulting proposal to unchanged atomic graph validation. This can remove isolated classification calls but needs an honest decomposition baseline: the current combined curator may not make a separate call for each type/edge.
3. At host admission/projection as a truth or permission gate: rejected. Model scores cannot authenticate source actors, establish entailment, grant permissions, rewrite IDs or suppress original governing intent.

Start with node/proposition type, directed pair relation semantics and source-to-claim support status. These are separate tasks, not one overloaded categorical label. Preserve independent axes (type, standing, applicability, attribution). The present graph has ONE `kind` per node. A passage can express several propositions (for example a task AND its independent completion constraint): the upstream proposer must produce separately addressable units with their own IDs/source evidence before single-kind classification. CLEF chooses one declared kind or unknown for each such unit; it does not emit a multi-kind existing node or silently split/merge identities. Additional role/applicability axes remain separate assessments, not extra `Node.kind` values. Test a mixed request yielding two separate records and preserved delivery of the independent constraint; conditional classification over already-split units alone earns no extraction credit. `unknown/insufficient-context` is explicit; `none` means evaluated no-relation, not absent candidates or missing input. Supersession, causality, contradiction and cancellation need exact scope/time/source evidence and negative controls, not lexical similarity. Support classification remains a model assessment, not a protected host fact.

Candidate generation is a separate owner. A decision head supplied with a complete candidate set may classify it but cannot discover missing propositions by selecting from that set. First measure conditional classification on fixed independent candidates; then measure an actual proposal-plus-classification pipeline with candidate recall counted in end-to-end results. No oracle candidate set is credited as practical extraction.

## 3. Proposed staged pilots

### P0: actual deployment and adapter acceptance

Inspect only the designated deployment/API/configuration, without credentials disclosure or mutation. The located configuration is `paddock` commit62882f8737a4b232069cbf15992de38a91a14405, clean when inspected. Historical100-question probability discrepancy in the deployment report is not our new result or a calibration conclusion. Bind exact model/head/tokenizer revision, quantization, server build, hardware if observable, context/admission behavior and native endpoint. Its observed state slices are a warning to test the actual server, not proof the local deployment truncates. Require full source/schema admission or explicit incomplete/unavailable status. Test distinguishing evidence at start/middle/end and exact tokenization/budget accounting if available. Sentinel success alone does not prove absence of truncation. If actual completeness cannot be established, report that limitation and do not claim full-source replacement acceptance.

Mechanical contract suite: ordered IDs; exact questions/options; finite non-Boolean numbers; valid domains and probability mass; missing/extra/malformed answers; duplicate IDs; stale revisions; cross-scope candidates; no silent server truncation; HTTP timeout/cancellation/response bounds; source data instructions cannot become host instructions; derived advice is noneligible and cannot qualify explicit intent or mint host facts; mixed passages retain separately identified task and constraint; no graph mutation on failure. Shared deterministic business/adapter tests run against a hand-written dummy and owned HTTP fixture through the same port. These do not establish real-model semantics. The real deployed leg is separately required and cannot be replaced by dummy success. Performance is a separate suite.

### P1: conditional classification and selective replacement

Independently authored new fictional developer-session families, split by family—not random near-duplicate rows—into development, calibration and sealed test. Labels have source-span rationales and explicit ambiguous/unanswerable cases; adjudicator uncertainty is retained. The runtime/integration author must not receive sealed expectations. Prompts/schema freeze before sealed cases are opened. No private historical indexed content or old pilot private oracle is sent to either model.

Task families: proposition/node typing; directed edge classification; source support assessment. Controls include task versus completion constraint, attempted versus observed action, claim versus tool observation, hypothesis versus causal finding, current versus historical test coverage, same-byte new generation, scoped cancellation, quotation versus real request, two independent hypotheses with similar wording, insufficient source, no-relation, reverse direction and incompatible scope. Host-known source identities are provided as evidence, not classification targets. Include held-out paraphrases, positions, distractors and novel combinations, not only renamed templates.

Matched decision arms: deterministic applicable rules; fixed LLM classifier; CLEF alone; CLEF with frozen abstention-to-LLM policy. Same candidate/schema/source package for conditional comparisons; native output encodings may differ and are disclosed. Advisory-to-curator effects require P2, not these independent decisions. Fix raw uncalibrated arm and any calibration method using only development/calibration. No threshold chosen on final test. If calibration data do not justify replacement at useful coverage, report infeasibility rather than force a threshold or call zero acceptance success. No model/call/token/spending caps are introduced; roster size is an experimental sampling choice frozen before outcomes, not an execution quota.

Quality first: per-class confusion/F1, directional relation precision/recall, critical false strengthening/retirement, source support precision, unknown handling; conditional candidate metrics separately from end-to-end recall. Calibration/selection: reliability, Brier/NLL where labels permit, accepted/total, error among accepted and all-case system error after actual LLM deferral. Cluster-family uncertainty and finite-count intervals; no i.i.d. assertion across paraphrases. Score zero accepted as N/A risk, not zero error. LLM agreement is not ground truth. Expose disagreement cases for independent assessment without feeding test corrections back into that original run.

### P2: integrated maintenance and workflow

Only after P0 and a bounded P1 result, freeze new session episodes and arms: unchanged combined curator baseline; same curator plus CLEF advisory observations; explicitly decomposed proposal/classification/composition baseline; that decomposition with selective CLEF replacement. The decomposition-only arm prevents attributing architecture changes to CLEF. This is four distinct bundles unless a documented implementation proves placements coincide. Do not claim removal of an existing call merely because a hypothetical per-node LLM call was avoided.

Initially replay a frozen event stream to isolate maintenance outputs and verify live classifier integration. This is a real-model replay pilot, not an interactive agent-benefit result. Then run new actual worker/curator closed-loop episodes for promising frozen configurations; actual endogenous trajectories differ, with all arms receiving the same exogenous contract and public tools. Count fresh request/quote exposure before action, actual graph delivery, source retrieval, correct constraint retention, no resurrection of cancelled work and exact after-write action requirements. Protected facts, stable-ID deltas, CAS and source isolation stay unchanged.

Advisory disagreement may reveal defects or amplify false suggestions. Measure both with correct/incorrect-advice controls declared separately from genuine CLEF predictions; synthetic injected advice tests instrument behavior only. Preserve rejected deltas, failed frontiers and unchanged last-valid heads. Curator fallback is explicit and recorded, not invisible retries/JSON repair. No automatic same-frontier rescue; an original failure remains in the roster.

## 4. Performance and decision criteria

After quality judgments freeze, compute matching-boundary latency/throughput: request admission→full typed result, preprocessing/serialization/queue/transfer/model/postprocessing where independently observable, and total maintenance boundary→usable committed projection. Report p50/p95 only with sample counts and estimator definition, cold and warm separately, actual batching/concurrency/competitors/cache state, all timeout/error rates and latency distributions including failures as censored/failed—not dropped. Paired order blocks and declared warmups/repeats reduce drift; do not repeatedly run until a favorable sample appears. One joint request is not one independent decision sample.

Actual realized LLM-call reduction, fallback rate, LLM tokens, local CLEF requests/question counts and available GPU consumption are separate. Static model parameter counts, publisher latency, zero local API price or fewer output tokens do not establish end-to-end speedup or lower total resource use. Include proposal calls, classifier calls, curator calls, failed calls and transport overhead; never add overlapping SDK/provider token components. Advisory can improve quality while being slower; replacement can be faster yet omit critical relations. Publish the trade-off frontier, not a single aggregate score that hides these cases.

A finding of useful fit requires actual eligible-task quality, maintained downstream contracts and observed end-to-end improvement or useful quality gain at disclosed additional work. No critical semantic regression is excused by aggregate F1. Acceptance margins, case roster, critical strata, workload/batch settings and routing thresholds remain prospective and must be fixed before measured test calls; this draft invents neither a production risk target nor a financial budget. Human benefit and general deployment readiness are outside these pilot claims.

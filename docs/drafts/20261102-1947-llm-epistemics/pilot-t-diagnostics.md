## What changed

The earlier public inventory found ten generic governing-context errors across six
graph users. Diagnostics003 distinguishes omitted current relation heads from
relations still attached to an older definition. Both can apply simultaneously.
It also identifies stale bound definitions and non-Task progress targets.

Versioned `runner/{diagnostics_t_003,ledger_t_003,backend_t_003,instrument_t_003}.py`
adds a bounded structured sidecar to applicable rejection responses. It preserves
repair002's admission gates, validation order, legacy code/detail and transaction
semantics. It neither selects context nor repairs the caller's request.

- Per-operation errors identify the index and a bounded alias. Where established,
  JSON pointers identify bind `/definition` or `/context`, and state `/subject`.
  Referenced binding/content errors are not nonexistent state input fields.
- Final packet, final selected-context and encoding failures are batch-scoped.
  A later relation can invalidate an earlier binding: the last operation is not
  automatically the cause. A reason can still identify the affected binding.
- Rejection references describe the tentative validation state, not an admission
  receipt. Rejected allocated identities can subsequently be reused. An admitted
  structure still does not certify truth, semantic support or Human approval.
- The sidecar is bounded to8,192bytes. An oversized reason is omitted wholly with
  explicit type/cause and context counts, never truncated into false identities.
  This is not a bound on the complete legacy response or audit record.
- Pretransaction request-envelope, read/find/workspace and SDK errors retain
  their existing envelopes. Generic operation errors need not identify a field.
  Infrastructure exceptions remain infrastructure failures.

The copied backend/CLI preserve the diagnostic end to end; audit and returned
backend payload agree. The preparer stamps `pilot-t-diagnostics-003`. Original T
and002 files, trusted directories, registration, verdicts and publication remain
unchanged. Frozen measured controller/auditor wiring still means historical T;
this preparer is not a new registered experiment or native-provider readiness.

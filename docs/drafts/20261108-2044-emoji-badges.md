# Pi border badge emoji proposal

Original scope: implement Cuckoo's bird badge and propose the other identities.
Subsequently approved: goals 🎯, subagents 👥, background tasks 🛠️, Codegraph 🕸️,
decisions 📥, and context archive 🗃️. All other badges and controls remain
unchanged. There is no dedicated Unicode cuckoo emoji; use 🐦.

| Badge | Current identity (normal / compact) | Proposed identity |
| --- | --- | --- |
| Cuckoo | Cuckoo / C | 🐦 (implemented) |
| Background tasks | bg / ⚙ | 🛠️ (implemented) |
| Codegraph | CG / cg with state glyph | 🕸️ (implemented; compact retains state glyph) |
| Goals | goal / state-dependent target/error glyph | 🎯 (implemented; compact retains paused/error marker) |
| Context archive | CTX / CTX | 🗃️ (implemented; retains fault marker) |
| Decisions | ? / ? | 📥 (implemented; retains both counters and shortcut) |
| Historian | HIST / H | 📚 |
| Subagents | agents / ◈ | 👥 (implemented) |
| Tokemon | Provider name and quota metrics; no fixed identity label | 🔋 plus provider name and metrics |

Keep all counts, unknown `?`, warnings `!`, activity, disabled state, shortcuts,
pending arrows, provider names, and quota measurements. Replace only identity
labels, not semantic state. Cuckoo's current compact form omits `off`; this change
preserves that pre-existing behavior rather than expanding scope. Historian's
compact form currently loses activity/error state; preserve it if that badge is
redesigned. Goal compact state distinctions must also survive emoji replacement.

Separate bottom-right controls: propose 🤖 for model and 🧠 for thinking, while
retaining model ID, thinking level, shortcuts, queued-value arrows, and click
regions. The compact controls' custom width calculation assumes one-column
glyphs; any emoji implementation must use measured terminal-cell widths.

Search hub, fast mode, retry extensions, performance and usage views do not own
border badges. Tokemon is top-right; the other badge owners above are bottom-left.

The read-only inventory was delegated and reviewed against the badge-owner
source locations: each extension's index and its status/presentation/view helper.
No useful new skill candidate beyond existing testing/TUI procedures emerged.

# Cuckoo selectable checkpoints

## Behavior

(up to three rows), with only the selected checkpoint's detail below it.
`j`/`k` and arrows select; Ctrl-U/Ctrl-D and Home/End scroll detail. Key hints
remain fixed. Settings follow the detail in the scrollable body; runtime errors
precede it. History retains timestamp, branch and entry-ID attribution. RPC/plain
output remains complete and flat. No cadence, schema or inference changes.

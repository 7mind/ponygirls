# UI/UX review of the Pi extensions and command-line tools

Date: 2026-11-17. Scope: the Pi extensions and CLI tools built by this flake.
Tools from other flakes (`bullshit`, `flurry`, `onyx-run`, the gateway
`ponygirls-subagents` variant) were not reviewed.

Method: every pane was driven as a user in a private tmux server
(`./pi-test`, 80, 120 and 170 columns); CLI help and error paths were run
from the built packages. Proposed designs were published as mockups (Manure
artifact `96ab9796f8e2c96f107429654747a886`) and approved in decision Q86
("All yes"). The finished screens are published as-built (Manure artifact
`a69a7ace0041c16c5377751575649798`).

The rules that came out of the review are in
[`nix/pkg/pi-extensions/ponygirls-pi-ui/CONVENTIONS.md`](../../nix/pkg/pi-extensions/ponygirls-pi-ui/CONVENTIONS.md).

## Defects found and fixed

| Where | Defect | Fix |
|---|---|---|
| `pi-test` | Did not start ("no extensions found"); failed on a non-NixOS host and in a linked worktree; loaded the deployed search hub | Parses the packaged extension list, links the packaged shared libraries, binds the loader, the Nix profile and the Git common directory, builds the flake's `pi-search-hub` |
| Border badges | Changed places on every update and started in initialisation order | Pi patch `widget-order.patch`: `setWidget` takes `order`; each badge has a fixed place (`BORDER_ORDER`) |
| bg-tasks | A status-backend error at startup started a model turn nobody asked for; the notice was cut mid-word | A notice starts a turn only while a task runs; `--no-session` is said once; one-line notices |
| `/bg` | A task the user terminated was shown as a red failure; hints for finished tasks offered terminate/signal | `■ terminated`; hints follow the selection |
| Settings panel | The notice line was printed twice; state buried in standing disclaimers | Redesigned (below) |
| `/usage` | Last column clipped at 120 columns while an empty column wasted 24 cells; mixed number formats; locale-dependent grouping | One tree column, whole columns dropped and named, kit formats |
| `/perf` | Model names cut to six cells at 120 columns; three stacked tables | Period tabs, the model column keeps its width, short and full column sets |
| tokemon (pane and CLI) | Narrow terminals hid Provider and Status first; piped `--once` squeezed columns to one cell | Provider, Window, Used / limit and Status never hidden |
| `/agents` | Detail line cut at the edge; two actions both called "close"; blank transcript while loading | One state column, wrapped details, hints by state, loading text |
| `frameTitle` (kit) | Tabs were cut from the right, which could remove the active tab | The active tab and its neighbours stay; `‹`/`›` mark the hidden side |
| Codex limits | Warned at every start that no limit was discovered, before discovery could run | The warning waits for a completed discovery |
| Codegraph | Another process holding the index lock was reported as an error | The last state stands, the next query syncs, status says `busy elsewhere` |
| `chronicle-collector` | `--help` answered with a JSON error and exit 1; usage errors did not name the argument | Text help with exit 0; usage errors name the argument, exit 2; control commands answer in sentences (`--json` keeps the JSON) |
| `reattach-llm` | `--help` failed on an environment check | Help and argument validation run first |
| `yolo` | A mistyped command started the clipboard broker first; no-argument run printed the full help with a failure status; `--env` without a value looped | Arguments are validated before any side effect; usage errors exit 2 |

## Redesigns (approved as mockups)

- **Badges**: one look (`borderBadge`): the glyph, then a label coloured by
  state; a badge with nothing to report is its glyph alone.
- **Scoped settings panel** (shared by five extensions): columns SETTING, HERE,
  EFFECTIVE; staged changes marked on the row, the tab and the footer; hints
  list only the keys that apply; row notes say what a setting still needs.
- **Status views**: `/historian` and `/context-archive` are state-first facts
  (`FactsView`) with the previous complete text behind `d`; `/cg` is a table
  pane and is what bare `/cg` shows; `/fast status` and `/codex-limits` state
  the answer first.
- **Goal transcript**: one line per goal event; sidecar revisions are not drawn
  in the collapsed transcript.
- **`/websearch`**: one table with word headers and a tier column; policy and
  legend behind `?`.
- **Key hints**: one vocabulary (`KEY`, `HINT`, `ctrlKey`) in every pane.
- **Command descriptions**: at most 60 characters; syntax lives in completion.
- **`yolo`**: the launch trace is opt-in (`--trace` or `YOLO_TRACE=1`).

## Where the result differs from the mockups

- Settings panel: ASCII checkboxes; the label "Automatic mode" is kept; the
  save target is a line under the description.
- Decisions badge: the number is in the warning colour when this session waits
  and muted when only other sessions do.
- Agents badge: `3 ●2 ?1` (running and asking marks as in the pane).
- `/websearch`: LAST shows the outcome without an age (the monitor records no
  completion time; its data model was left alone).
- Goal: Pi drops an entry whose renderer returns nothing, so a revision entry
  appended while the transcript is collapsed is not drawn by a later ctrl+o.
  It is drawn when the transcript is built expanded and is always persisted.
- Decisions pane: the key symbols chosen on 2026-11-06 (⎋ ⇥ ⌃S) were replaced
  by the shared words.

## Verification

- Every flake check whose derivation differs from `main` was built on the
  final tree, except three VM checks (`manure-vm`, `service-unit-graph-vm`,
  `hm-service-unit-graph-vm`): this host has no KVM.
- Chronicle collector: `npm run typecheck` and `npm test` in the pinned shell
  (158 tests, 0 failures, 0 skipped) and the `chronicle-collector` check. The
  other Chronicle suites were not run; only `chronicle/collector` changed.
- Each fix has a test that failed first for the stated reason.
- Live terminal pass at 80, 120 and 170 columns over every changed pane.

## Known, not changed

- The Manure CLI reports a missing command as "arguments are required: cmd".
  `manure/manure/cli.py` is an input of the whole Manure validation matrix,
  including VM checks that cannot run here; the wording fix was reverted.
- Seen once: after a large checkout change Codegraph reported "Index not
  ready" as an error and was ready half a minute later.
- A locally built `yolo` on a non-NixOS host cannot run host binaries from
  `/usr/bin` inside the sandbox (the loader bind); the deployed one behaves
  the same way.
- `/perf` test fixtures follow a real capture's latency figures and request
  counts; no account data.

## Implementation

`nix/pkg/pi-extensions/ponygirls-cuckoo/` contains shared-library settings,
strict JSON decoding, branch-sensitive report restoration, main-model boundary
scheduling, interruption/cancellation handling, UI and behavioral tests.
`README.md` documents commands, bootstrap/rebaseline rules, error handling and
limitations. Home Manager registers the extension without managing mutable
`cuckoo.json`. The Nix check typechecks and runs all tests; module assertions
check registration and that preferences remain unmanaged.

No Chronicle application changes. No live model calls, external disclosure,
Home Manager activation or push was performed.

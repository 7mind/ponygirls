## Provisional native boundary

Java class `manure.storage.PosixNative`, explicit `shared(String absoluteLibraryPath)` and `linked()` factories, no fallback. Methods below are instance native methods; names/errors must be kept consistent between C and Scala writers:

- `int openRoot(byte[] absolutePath)` — no-follow every root component, existing directory only.
- `int openDirectory(int parent, byte[] name)` — component-only no-follow directory open.
- `void mkdir(int parent, byte[] name)` — mode 0700, no path fallback.
- `int createFile(int parent, byte[] name)` — CREATE_NEW, mode 0600, pinned regular handle.
- `int openFile(int parent, byte[] name, boolean writable)` — pinned/verified regular file; FIFO/device rejection without blocking or device-open effects.
- `long[] identity(int fd)` — kernel dev/ino; callers format unsigned values.
- `int kind(int parent, byte[] name)` — no-follow type, constants REGULAR=1, DIRECTORY=2, SYMLINK=3, OTHER=4.
- `byte[][] entries(int directory, int maxEntries)` — bounded raw names, excludes dot entries, independent directory offset.
- `byte[] read(int fd, long offset, int maxBytes)`; `void write(int fd, long offset, byte[] bytes)` — positional, exact-progress semantics.
- `long size(int fd)`; `void truncate(int fd, long size)` — verified regular fd, checked nonnegative 64-bit sizes; groundwork for recovery, not a recovery state machine.
- `void sync(int fd)`; `void move(int sourceParent, byte[] source, int destinationParent, byte[] destination)`; `void unlink(int parent, byte[] name, boolean directory)`.
- `int claim(byte[] abstractSocketName)` — Linux kernel-lifetime AF_UNIX abstract bind, CLOEXEC; no unlink/PID-file fallback.
- `void close(int fd)` — Linux close once, never retry a possibly reused fd.

`NativeFailure extends IOException` exposes errno and fixed operation labels without payload/path leakage. JNI must validate components/embedded NUL, integer/range conversions and errno before cleanup. Scala maps stable file error types.

## Security/lifecycle decisions

- The Scala public boundary injects `PosixNative` explicitly; no ambient native-library path or mutable global registry. The loader is explicit shared vs static-linked, never a runtime fallback.
- Acquire the physical-root claim before payload effects. Match existing Python claim naming `manure-` + SHA256(unsigned-decimal-dev + ':' + unsigned-decimal-ino). This is interoperability for mutual exclusion, not legacy wire support. Abstract claims are scoped to the Linux network namespace; no global cross-namespace exclusion claim.
- Root close must retain ownership while child handles/work remain active (e.g. reject close until handles close); do not release the claim while pinned writable files still exist.
- Existing-file open needs more than an unsafe check/open/fstat sequence. Linux O_PATH pin + fstat before reopening the pinned inode through trusted procfs is an acceptable explicit bridge design, not an absolute payload-path fallback; require procfs and fail explicitly if unavailable. Validate inode/type on the final IO descriptor too. Record its trust/namespace assumptions. Do not open arbitrary devices to discover their type.
- No-follow traversal, raw-name non-traversing cleanup, file/directory fsync and rename remain independent primitives; availability does not implement the complete publish/metadata/recovery state machine.

## Acceptance

1. Reproduce previous actual native provider refusal; then demonstrate actual static-linked library solves it, no JVM fallback/dlopen dependency.
2. Same real-filesystem behavioral contracts on JVM and actual native executable: directory creation, existing regular opens, Unicode, symlinks, FIFO/device rejection, identity/replacement, bounded cleanup, fsync/rename and fd ownership.
3. Cross-process root contention, aliases/renames, crash release and no claim release with open handles; no lock-file cleanup races.
4. Nix shared/static libraries, offline common build, source filters, explicit validation scope and final package checks.
5. Review C/JNI correctness independently; preserve source/artifact identities and failures, merge safely into main and remove clean worktrees.

# Follow-up: preview only an archived test report — controlled real repairs

**Question and boundary (frozen before inference).** Does showing up to 160 verbatim UTF-16 units from each end of an explicitly named successful log-reader result help an agent repair a real defect, compared with leaving only the stock pointer? FIFO selection, protected recent suffix, digest, read/find capability and model capacity are unchanged. The original captured test run fails; the *reader* succeeded in retrieving its log. Do not extend preview to failed tool calls or every tool named `bash`/`read`.

**Cases.** Three purposively selected, public, benign one-module defects with pinned parent and fixing revisions: [toolz: empty interposition](https://github.com/pytoolz/toolz/commit/d2eba0374a452c2b18fe188b04527e22bda3548c), [more-itertools: very large numeric ranges](https://github.com/more-itertools/more-itertools/commit/c629214760c78c0a2235e896d335cccfb3a64466), [python-semver: integer-like subscripts](https://github.com/python-semver/python-semver/commit/9f6894daaf62d55fc37cece10948e7e1cc3dc369). Before model calls, demonstrate that baseline fails for the target behavior and the upstream fix passes the **same** independent executable tests, including held-out variants and existing-behavior checks. Generated evidence must contain the actual public failing run, not a manually constructed failure banner. Specify ports/subsets and the Python version; do not claim all upstream CI or an entire SWE-bench task. Exclude git history, gold diffs, fixed code, hidden tests and proprietary project content from every model input. Patches modify only the named baseline module.

**Comparison.** Three arms per defect and model: RAW (originals retained; same tool declarations), stock archive with exact `read`/substring `find`, and the same FIFO archive plus verbatim edges **only** on `read_test_report` (a separate non-log result stays pointer-only). Keep a long recent suffix; archive the same two eligible entries in both edited arms before the model starts the repair. Disclose that the intervening history/pressure is controlled; measure the default trigger separately rather than representing forced edits as normal production frequency. Match model, substantive prompts/inputs, access to original source, held-out tests, tool set and output limits; give each session an independent opaque prefix nonce and verify the actual selected slots/presentations. Model may inspect the pristine target file and use recall. Submit an edit, not a proposed fix description; grade once after the response in a fresh no-network sandbox. No ground-truth test failures passed back for iterative tuning. Record malformed/unapplicable edits, test failures, provider/transport failures, truncations and unscored questions separately. Never treat a stopped session as a cheaper completed repair. No new model call is made by the preview itself.

**Decision rule.** Two prespecified independent rounds, each 3 cases × 3 model routes (Token Factory DeepSeek V4.1 Flash and Kimi K3.1 Pro; Codex GPT-6.2 Sol) × 3 arms. Freeze cases, scorer and tested runtime before scoring; no redoing an unsuccessful model answer. Primary endpoint = patch applies to the real parent revision and passes the complete designated executable oracle. Secondary = whole-session model tokens including cached input and output, uncached input, wall time incl. tool continuations, and actual recall of original log vs other tool text. Report paired, not just pooled outcomes. To recommend promotion require no loss on any stock-solved matched repair in either round, plus either two distinct defect/model pairs rescued across the rounds, or ≥10% less total provider work (tokens or summed session time) vs stock in **each** round without >10% regression in the other measure. Require ≥8/9 valid matched pairs in each round with representation/target equality and at least 2 distinct defects solvable by stock; otherwise withhold promotion. RAW is a contextual control, not the primary comparator. These are practical decision thresholds, not a statistical claim. No tuning after seeing graded results or new deployment defaults from this pilot.

For directories, large or resumable uploads, scripted downloads and CI.

1 · Set up

Install

nix shell .#manure -c manure whoami

The Home Manager module installs manure and sets the variables below for you.

Point it at this server

export MANURE_URL=
export MANURE_TOKEN_FILE=~/.config/manure/token

The token file holds one access token. Create it under ; the secret is shown once.

Check

manure whoami
# prints the user and token this machine uses

2 · Use

Upload a file or a directory

manure upload ./site --access external --expires-in 7d
manure upload ./report.md --access public --tag release

--access internal|external|public is required. An external upload prints its password once; signed-in users can retrieve it later on the artifact page. An interrupted upload resumes when you repeat the command.

Download and verify

manure fetch <id> ./out
manure fetch <content-url> ./out --password-file ./pw

Find and manage

manure search 'access:public tag:release'
manure info <id>
manure rotate-password <id>
manure delete <id>

Search uses the same expression syntax as the Artifacts page. Add --json to any command for scripts.

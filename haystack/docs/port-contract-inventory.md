Old Node import-dependent tests and production entrypoint are retired after moving
these assertions. Only inert/frozen admission characterization remains under
`characterization/node`, with no listener/MCP/PG adapter. Real server/client gates
are `scripts/test-postgres-scala.sh`, `scripts/test-current.sh` (exact inventory,
JUnit/TAP and artifact hashes), web typecheck/tests/browser. Build/health/pure tests
are not substitutes for native/browser/PG acceptance. Reports state exact inputs,
nonempty discovered inventories and zero skips; earlier failing reports remain.

## Actual proxy/package acceptance

The HTTPS journey consumes actual evaluated NixOS module JSON (including its
declared ports, current generated `Failure`, locations and installed asset root),
never a retired nested error envelope or a local-dist root substitution. Filtered
sources may supply `HAYSTACK_PROXY_CONFIG_FILE` plus an explicit source revision;
invalid configured input cannot fall back to Git/evaluation. Browser prerequisites
are required, not successful skips. Fresh inventories, source/ELF-or-JAR and proxy
hashes are recorded and the supplied artifact/proxy must remain unchanged.

An earlier host fixture incorrectly accepted a preexisting loopback listener's
health before its own child bound. That attempt reached only health, unauthorized
whoami and a rejected synthetic login; it is not backend/proxy acceptance. No
unrelated process was stopped and no further probes were made after discovery.
Controlled owned-listener and stale-ready regressions now require zero probes;
new host proxy JSON must come from a new actual module evaluation with free ports,
not rewriting the old JSON. Free-port checks are observations, not reservations.

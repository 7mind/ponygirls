# Haystack review — 2026-10-08

Reviewed the application/storage boundary, browser navigation and editing,
HTTP/MCP authentication, Home Manager agent policy, reverse proxy, package,
and quick-preview workflow. Findings below were reproduced before their
corrections. Severity describes the original behavior; all seven are corrected
in this change.

| Severity | Finding | Reproduction and correction |
|---|---|---|
| P1 | Failed PostgreSQL commits returned an aborted transaction to the pool. A later valid operation could fail with `25P02`. | Inject a revision-insertion failure, then write a valid record using a one-connection pool. The original second write failed with `25P02`. `commit` now rolls back on every failure, discarding the connection if rollback fails. Regression: `server/tests/postgres.test.ts`, “rolls back failed commits before returning the connection”. |
| P2 | Search typing remounted Browse on every query change, dropping keyboard focus. | Type `hello` one character at a time. The original control failed to retain the complete query. Browse now retains its component identity; submitted queries update the fragment, and obsolete search responses are ignored. Regression: browser “query typing retains focus”. |
| P2 | Opening the attention inbox immediately rewrote `#/inbox` to a Browse URL. | Open the inbox and wait for its records; assert the fragment remains `#/inbox`. The original assertion failed. Inbox and Browse now have separate route-persistence behavior. Regression: browser “inbox route persists”. |
| P2 | Browse reconstructed qualified keys from decoded components, making records with reserved characters or Unicode inaccessible. | Seed `u%3Ani:caf%C3%A9%20%F0%9F%90%8E`, open it from Browse, and inspect the get request. The original request contained an invalid decoded key. Browser keys now use canonical component encoding, including relationship links. Regression: browser “canonical keys survive browsing”. |
| P2 | Browser UUIDv7 request IDs contained random bytes instead of the required timestamp. | Decode the first 48 bits and compare with the creation time. Original sample timestamp: `68039064863752`, outside `1791450833632..1791450833643`. The generator now writes Unix milliseconds into those bytes. Regression: `web/tests/api.test.ts`. |
| P2 | The preview rebuild detector ignored TSX, CSS, and build configuration. UI-only edits could keep serving an old bundle. | With `styles.css` newer than `server/dist/index.js`, the original `find … -name '*.ts'` detector returned an empty result. The detector now includes all frontend/server source files and build inputs, compared with both build outputs; installation uses the lockfile through `npm ci`. |
| P2 | Production shutdown closed the already-ended migration pool a second time and exited with status 1. | Start the built package, verify assets/API/WebSocket, send SIGTERM, and assert exit 0. The original package failed with `Called end on pool more than once`. Shutdown now closes only the repository's live pool. Regression: `server/tests/runtime.test.ts` and packaged runtime smoke. |

## Requested changes

When enabled, the shared Home Manager bundle instructs Claude, Codex, and Pi
to verify the authenticated GitHub account and account for upstream reports
and PRs. Matching authorship is distinguished from evidence of agent filing.
It also requires attempts to extract reusable skill candidates with subagents,
overlap analysis and provenance, then persist and verify useful drafts in
Haystack. Drafts remain inert. Disabled configurations contribute no policy
or Haystack MCP entry; Linux, Darwin, and NixOS-mapped configurations are
covered by evaluation checks.

The browser has a responsive workspace, navigation presets, record cards on
mobile, editing and history panels, and persistent connection diagnostics.
HTTP and MCP commits share one publishing repository boundary. WebSocket
recovery follows the explicitly requested resilient-ws-ui skill and was
informed by [cq4](https://github.com/pshirshov/cq4) and the
[reference implementation](https://github.com/pshirshov/ws-reconnect-demo).

## Limits

The notification feed covers HTTP/MCP writes through one process, not
direct SQL or other server instances. Reconnect refetches current state;
there is no durable event replay. Main-thread browser timers can be throttled
while hidden; recovery is performed when visible or resumed. Lifecycle
checks dispatch browser events and exercise recovery paths; they do not
prove behavior for every OS sleep, network migration, or real BFCache policy.
No deployment or live GitHub-account audit was performed.

## Preview follow-up

The LAN preview exposed an additional P2 defect: the browser heartbeat used
`crypto.randomUUID`, which is unavailable on non-secure HTTP origins. A real
Chromium session at `http://haystack.test` authenticated successfully but
remained Connecting and raised `crypto.randomUUID is not a function`.
Heartbeat nonces now use the existing UUID generator based on
`crypto.getRandomValues`. The same browser reproduction now reaches Live
without page errors.

The interface now uses direct labels, reduced spacing, square corners, and
light/dark palettes selected by `prefers-color-scheme`. Native controls follow
the same scheme. Query completion appears below the input, supports
caret-aware replacement, keyboard and pointer selection, Ctrl+Space,
Escape dismissal, and ignores responses received after dismissal.

Validation: type checks, production builds, eight client checks, and eighteen
real Chromium/PostgreSQL scenarios including non-secure-origin heartbeat,
completion insertion and delayed-response dismissal, and live system-theme
changes. Desktop/mobile screenshots were inspected in both themes.

## Semantic fields follow-up

Top-level fields now render by their JSON type, including exact number text
and highlighted, indented objects/arrays. Typed `md`, `code`, and `text` nodes
format explicit content; Markdown includes highlighted YAML frontmatter and
fenced code. Raw JSON and Markdown source remain available, and history
views share the renderer. Unknown/malformed nodes preserve their complete
data. HTML/code is inert and images require explicit navigation.

The shared Home Manager policy now explains these shapes and requires full
SKILL.md drafts in `fields.skill` as typed Markdown, with metadata in sibling
fields. See [field presentation](field-presentation.md) for the convention.

Validation also reproduced a P2 search race: with delayed hash navigation,
submitting `hello` and immediately editing `bogus:1` changed the input back
to `hello`. Route updates now preserve newer drafts when reflecting the
submitted state, while new navigation still initializes its own filters.
The browser regression exercises that delay and verifies the draft survives.

Final validation: thirteen client checks, twenty-two Chromium/PostgreSQL
scenarios, TypeScript checks and production builds, shared Home Manager
policy evaluation across Linux/Darwin/mapped configurations, and the Nix
package build with the refreshed dependency hash.
